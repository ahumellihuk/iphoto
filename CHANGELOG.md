## [0.1.0] - 2026-02-15

### Added

- Interactive archival workflow with scan, archive, resume, verify, retry, and status commands.
- OSS contributor/agent docs (`AGENTS.md`, `CONTRIBUTING.md`, `SECURITY.md`).
