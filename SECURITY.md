# Security Policy

## Supported Versions

Security fixes are applied to the latest `main` branch and the latest tagged release.

## Reporting a Vulnerability

Please do not open public issues for security problems.

Report privately by emailing: cam@oconnell.sh

Include:
- affected version or commit
- reproduction steps
- impact assessment
- any proposed mitigation

We will acknowledge receipt within 72 hours and provide status updates as triage progresses.
